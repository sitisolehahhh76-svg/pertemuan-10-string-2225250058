2. Penjelasan Materi

A. Variabel String

String adalah tipe data yang digunakan untuk menyimpan teks atau kumpulan karakter. String dapat ditulis menggunakan tanda petik satu, tanda petik dua, atau tanda petik tiga.

B. Indeks dan Slicing

Indeks digunakan untuk mengambil karakter tertentu dalam string. Slicing digunakan untuk mengambil sebagian karakter dari string berdasarkan posisi yang ditentukan.

C. Membersihkan Teks

Metode "strip()" digunakan untuk menghapus spasi di awal dan akhir teks. Metode "title()" digunakan untuk membuat huruf pertama setiap kata menjadi huruf kapital, sedangkan "upper()" dan "lower()" digunakan untuk mengubah huruf menjadi kapital atau huruf kecil.

D. Metode "split()" dan "join()"

Metode "split()" digunakan untuk memisahkan teks menjadi beberapa kata dalam bentuk list. Sementara itu, "join()" digunakan untuk menggabungkan beberapa kata menjadi sebuah string.

E. Pencarian Teks

Operator "in" digunakan untuk memeriksa apakah suatu kata terdapat dalam teks. Metode "count()" digunakan untuk menghitung kemunculan kata, sedangkan "find()" digunakan untuk mencari posisi pertama kata dalam teks.

F. Fungsi Python

Fungsi digunakan untuk mengelompokkan kode agar dapat digunakan kembali. Pada praktikum ini, fungsi digunakan untuk melakukan normalisasi nama dan menghitung jumlah kata.
